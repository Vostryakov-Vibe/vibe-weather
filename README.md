# vibe-weather
## Телеграм‑бот погоды с качеством воздуха

Проект представляет собой телеграм‑бота на Python, который показывает текущую погоду, расширенные данные, прогноз на 5 дней и отправляет периодические уведомления. Дополнительно бот оценивает качество воздуха по европейской шкале AQI Europe на основе концентрации PM2.5.

### Основные возможности

- **Текущая погода**
  - Температура и ощущаемая температура
  - Влажность, давление, облачность, скорость ветра
  - Время восхода и заката
  - Качество воздуха по PM2.5 с текстовой расшифровкой
  - УФ‑индекс с рекомендациями по защите от солнца

- **Прогноз на 5 дней**
  - Краткий агрегированный прогноз по дням (min/max температура и краткое описание)
  - Интерактивные кнопки по дням для просмотра детального почасового прогноза

- **Расширенные данные**
  - Детализированный отчёт по погоде
  - Загрязнители воздуха (PM2.5, PM10, NO₂, SO₂, O₃, CO) с краткими пояснениями

- **Геолокация**
  - Сохранение координат пользователя по отправленной локации
  - Обратное геокодирование в человекочитаемый адрес

- **Сравнение городов**
  - Быстрое сравнение текущей температуры в двух городах

- **Уведомления**
  - Автоматические уведомления о погоде для сохранённой локации
  - Настраиваемый интервал: каждые 30 минут, 1 час или 2 часа

### Используемые API и данные

- **Погода и прогноз** — OpenWeather (`/weather`, `/forecast`)
- **Качество воздуха** — OpenWeather (`/air_pollution`, компоненты PM2.5 и др.)
- **Адреса / геокодирование** — Nominatim (OpenStreetMap)
- **УФ‑индекс (резерв)** — Open‑Meteo (если OpenWeather One Call не отдаёт `uvi`)

Оценка качества воздуха по PM2.5 выполняется по шкале **Air Quality Index (AQI Europe)**:

- 0–15   — очень низкое загрязнение  
- 15–30  — низкое загрязнение  
- 30–55  — среднее загрязнение  
- 55–110 — высокое загрязнение  
- >110   — очень высокое загрязнение  

Все текстовые пояснения выводятся пользователю **на русском языке**.

### Установка и запуск

1. **Клонируйте проект** и перейдите в его папку.
2. **Создайте и активируйте виртуальное окружение** (рекомендуется).
3. **Установите зависимости**:
   ```bash
   pip install -r requirements.txt
   ```
4. **Создайте файл `.env`** в корне проекта и добавьте в него:
   ```env
   BOT_TOKEN=ваш_телеграм_токен
   OW_API_KEY=ваш_ключ_OpenWeather
   ```
5. **Запустите бота**:
   ```bash
   python bot.py
   ```

После запуска перейдите в Telegram, найдите своего бота и выполните команду `/start`.

### Структура проекта

- `bot.py` — логика телеграм‑бота, обработчики команд и сообщений, фоновый поток уведомлений.
- `weather_app.py` — работа с внешними API погоды, прогнозом, качеством воздуха и УФ‑индексом, формирование текстовых карточек.
- `storage.py` — хранение пользовательских настроек (город, координаты, параметры уведомлений) в файле `User_Data.json`.
- `User_Data.json` — база данных пользователей в формате JSON.

### Настройка уведомлений

В меню бота выберите пункт **«Уведомления»** и задайте нужный интервал.  
Фоновый поток в `bot.py` будет регулярно просматривать всех пользователей и отправлять карточку погоды тем, у кого уведомления включены и указана локация.
